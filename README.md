# 개념의 숲

교과서에서 배운 개념을 질문, 개념 연결, 새로운 상황에 적용, 확인 퀴즈의 흐름으로 탐구하는 한국어 학습 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 설치나 서버가 필요하지 않습니다.

## 사용 방법

- 예시 개념(과학·수학·사회)을 골라 탐구를 시작합니다.
- 단계별 생각과 설명은 현재 브라우저에 자동 저장됩니다.
- **개념 추가**에서 교과서 개념과 핵심 질문, 설명, 활동, 퀴즈를 입력해 나만의 학습 노트를 만들 수 있습니다.
- 퀴즈를 마치면 학습 기록과 경험치가 저장됩니다. 기록은 사용 중인 브라우저의 로컬 저장소에 보관되며 다른 기기와 동기화되지 않습니다.
